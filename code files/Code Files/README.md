# EduGenie Code Files

Separate backend code files for the EduGenie AI-Powered Learning Assistant.

## Important
Do NOT upload your real `.env` file or Gemini API key to public GitHub.

Create `.env` locally using `.env.example`.

## Run

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

Open: http://127.0.0.1:8000
